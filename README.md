
# TSS - Proiect de laborator

**Disciplina:** Testarea Sistemelor Software  
**Program:** Master Inginerie Software, FMI - Universitatea din Bucuresti

## Descriere
Proiectul analizeaza secventele maximale strict crescatoare dintr-un vector de numere intregi, utilizand metode de testare functionala, structurala si mutation testing.

## Tehnologii
- Java
- Maven
- JUnit
- Instrumente de code coverage si mutation testing

## Cerinte
1. Equivalence Partitioning, Boundary Value Analysis si Cause-Effect Graphing
2. Code Coverage
3. Graf de control si complexitate ciclomatica
4. MC/DC
5. Mutant echivalent de ordinul 1
6. Mutanti neechivalenti omorati/neomorati
7. Mutation Testing cu doua instrumente
